SSO : le bastion vérifie la session portail + AccessGrant, puis injecte l’identité vers l’upstream (X-Forwarded-Email, X-Forwarded-User, …). L’appli doit accepter ces en-têtes de confiance (ex. Open WebUI : WEBUI_AUTH_TRUSTED_EMAIL_HEADER=X-Forwarded-Email et WEBUI_AUTH_TRUSTED_NAME_HEADER=X-Forwarded-User). Avec trusted headers, désactivez l’OAuth intégré de l’appli (ENABLE_OAUTH_SIGNUP=false) pour éviter le conflit avec le bouton Keycloak local. Déployez bastion-app (nouveau code auth) puis Appliquer l’infra (export nginx + reload) — sinon l’en-tête n’atteint jamais l’upstream.

En-tête X-WSSE (UsernameToken, digest SHA-1) régénéré à chaque requête par Nginx. Renseignez un identifiant et un mot de passe dans le credential vault ci-dessous.
